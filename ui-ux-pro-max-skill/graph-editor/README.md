# Graph Editor (Nodes & Edges)

A lightweight **web graph editor** prototype (nodes + edges) built using the **ui-ux-pro-max** design workflow.

## 🚀 Run locally

1. Open `index.html` in your browser.
2. Click the canvas to add a node.
3. Use **Connect nodes** mode to draw edges (click source then target).
4. Drag nodes to reposition.

## 🧠 Features

- Drag-and-drop nodes
- Create edges (directed undirected graph style)
- Select nodes and edges
- Delete selection (Delete key or Delete button)
- Export graph JSON to clipboard

## 🎨 Design notes

This editor follows the `ui-ux-pro-max` design system guidance (glassmorphism, vibrant accent colors, clear typography, accessibility checks).
