# PARI/GP 快速入门教程

## 什么是 PARI/GP？
PARI/GP 是一个专注于数论计算的计算机代数系统。它由法国波尔多大学开发，包含两个部分：
- **PARI**：用 C 语言实现的高性能数论算法库；
- **GP**：一种交互式解释型语言，可直接调用 PARI 的功能，语法简洁，上手极快。

无论你是想验证猜想、研究密码学、教学演示，还是进行大规模整数和多项式运算，PARI/GP 都能高效胜任。

---

## 1. 安装与启动
- **在线使用**（零安装）：  
  浏览器打开 [https://pari.math.u-bordeaux.fr/gp.html](https://pari.math.u-bordeaux.fr/gp.html) 即可直接编写运行代码。

- **本地安装**（推荐）：
  - Windows：前往官网下载安装包。
  - macOS：`brew install pari`
  - Linux（Debian/Ubuntu）：`sudo apt install pari-gp`
  
  安装完成后，在终端输入 `gp` 即可进入交互环境：

```
GP/PARI CALCULATOR Version 2.15.4 (released)
parisizemax = ...
? 
```

退出请输入 `\q` 或 `quit`。

## 2. 基本交互：计算器模式
`?` 是 GP 的提示符，直接输入表达式并按回车就能看到结果。  
上一结果用 `%` 引用，上一次前用 `%2` 等。

```gp
? 3 + 5 * 2
%1 = 13
? %1 ^ 2
%2 = 169
```

- 分号 `;` 会**抑制输出**，适合中间计算；
- 多语句放在同一行用 `;` 分隔。

```gp
? a = 2^100;    \\ 不显示结果
? a
%3 = 1267650600228229401496703205376
```

---

## 3. 变量与算术
变量赋值使用 `=`，区分大小写。  
避免用 `i`、`I`（虚数单位）、`Pi`、`Euler` 等内置常量名，但可以局部覆盖。

```gp
? x = 10; y = 3;
? x + y
%4 = 13
? x \ y      \\ 整数商
%5 = 3
? x % y      \\ 余数
%6 = 1
```

### ⚠️ 重点：有理数与浮点数
- **整数 / 整数 保留为最简分数**：
  ```gp
  ? 10 / 6
  %1 = 5/3
  ```
- 想得到近似小数，至少让一个数变成实数（加 `.0` 或用 `1.`）：
  ```gp
  ? 10 / 6.0
  %2 = 1.666666666666666666666666667
  ```
- 用 `sqrtn`、`exp` 等函数时，如果参数是整数会尝试给出精确结果或符号形式；想要数值用 `*1.0`。

## 4. 函数与自定义
GP 自带上千个内置函数，用 `? 函数名` 即可查看帮助。  
自定义函数非常简单：

```gp
? f(x) = x^2 + 1
? f(5)
%1 = 26
```

多行函数需要用花括号 `{ }` 括起来，并用 `my()` 声明局部变量：

```gp
? sum_n(n) = { my(s=0); for(i=1,n, s+=i); s }
? sum_n(100)
%2 = 5050
```

函数返回值是最后一个表达式的值，也可以使用 `return(...)` 提前返回。

## 5. 向量与矩阵
GP 从 1 开始索引。

```gp
? v = [2, 3, 5, 7, 11]
%1 = [2, 3, 5, 7, 11]
? v[3]
%2 = 5
? v[2..4]        \\ 切片
%3 = [3, 5, 7]

? m = [1,2; 3,4]  \\ 2x2 矩阵，分号换行
%4 =
[1 2]
[3 4]
? m[2,1]
%5 = 3
```

### 快速生成序列
```gp
? vector(10, i, i^2)       \\ 1^2, 2^2, ..., 10^2
%1 = [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

? [ i^2 | i <- [2,3,5,7] ]  \\ 集合推导式
%2 = [4, 9, 25, 49]
```

## 7. 数论运算亮点
这是 PARI/GP 的核心强项，几乎涵盖了基础数论与代数数论所有常用操作。

```gp
? factor(123456789)          \\ 整数分解
%1 = [3 2; 3607 1; 3803 1]
? isprime(2^31 - 1)          \\ 素数判断（1真0假）
%2 = 1
? nextprime(10^10)           \\ 下一个素数
%3 = 10000000019
? gcd(12345, 54321)
%4 = 3
? Mod(3,7)^(-1)              \\ 模7下3的逆元
%5 = Mod(5, 7)
? chinese(Mod(1,3), Mod(2,5)) \\ 中国剩余定理
%6 = Mod(7, 15)
? eulerphi(100)              \\ 欧拉函数 φ
%7 = 40
? sigma(120, 2)              \\ 所有因子的平方和
%8 = 38440
? divisors(36)               \\ 列出所有因子
%9 = [1, 2, 3, 4, 6, 9, 12, 18, 36]
```

### 实数求解与多项式
```gp
? solve(x=0, 1, sin(x) - 0.5)  \\ 求 f(x)=0 的根，区间内需变号
%1 = 0.5235987755982988730771072305
? polroots(x^3 - x - 1)        \\ 多项式所有复根
%2 = [1.324717957244746025960908854, ...] 
? p = x^2 + 1; factor(p)       \\ 默认在Q上分解
%3 = x^2 + 1
? factor(p * Mod(1,5))         \\ 在有限域F_5上分解
%4 = (Mod(1,5)*x + Mod(2,5)) * (Mod(1,5)*x + Mod(3,5))
```

## 11. 一个快速示例：寻找水仙花数
“水仙花数”指各位数字的立方和等于自身的数（如153）。用 GP 几行实现：

```gp
? for(n=100, 999, d=digits(n); if(n == sum(i=1,#d,d[i]^3), print(n)))

370
371
407
```

另一个例子：验证 100 以内哥德巴赫猜想：

```gp
? forstep(n=4, 100, 2,
    forprime(p=3, n, if(isprime(n-p), print(n,"=",p,"+",n-p); break)))
4=2+2
6=3+3
...
100=3+97
```
