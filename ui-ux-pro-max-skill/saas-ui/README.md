# Math Computing VM Landing Page

This folder contains a simple responsive landing page for **Math Computing VM** — a fictional SaaS product that provides high-performance virtual machines preconfigured for mathematics, simulation, and data science workloads.

## 🚀 How to run

You can open `index.html` directly in a browser, or serve it with a local server for best results (to avoid restrictions on `file://` URLs).

### Using Python (recommended)

```sh
python -m http.server 8000
```

Then visit: http://localhost:8000

### Using Node.js

```sh
npx serve .
```

## 📦 Files

- `index.html` — Landing page markup
- `styles.css` — Styles and responsive layout
- `script.js` — Small UI interactivity for mobile nav

## ✨ Customize
Update text, pricing, and features directly in `index.html`, or tweak styling in `styles.css` to match your brand.
