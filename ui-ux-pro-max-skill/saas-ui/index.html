Frequently asked questions

Answers to the most common questions from math teams and researchers.

Can I bring my own license (MATLAB, Maple, etc.)?

Yes. You can install your licensed software inside the VM and connect it to your license server. We also support installing open-source alternatives like GNU Octave and SymPy.

How do I access the VM remotely?

Each VM provides secure SSH access and a built-in Jupyter endpoint. You can also connect via VS Code Remote SSH or through a private VPN tunnel.

How is my data protected?

All storage is encrypted at rest and in transit. VMs run in isolated networks and we offer optional private networking and IAM controls.

What happens when the VM is stopped?

Stopped VMs do not incur compute charges (only storage). You can resume in seconds with your environment and data intact.
