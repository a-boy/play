在批处理文件（.bat）中，可以使用以下方法添加注释：

### 1. **`REM` 命令（最常用）**
```batch
REM 这是单行注释
echo Hello World  REM 行尾注释（注意：命令和REM之间需要有空格）
```

### 2. **双冒号 `::`（高效替代）**
```batch
:: 这是注释（执行效率比REM高）
echo Hello World :: 这不是注释！会输出"::"
```

> ⚠️ 注意：双冒号在括号代码块内可能出错，此时需用`REM`

### 3. **多行注释技巧**
```batch
goto :start
这可以是多行注释文本
任何内容都不会被执行
甚至特殊字符如 % ^ > 
:start

REM 实际执行内容从这里开始
echo Batch file started
```

### 4. **行内注释**
```batch
dir > nul && (  REM 成功执行dir后注释
    echo Directory listed  REM 子命令注释
) || echo Failed  REM 失败时注释
```

### 重要区别说明：
| 方法     | 括号代码块内 | 特殊字符处理 | 执行效率 |
|----------|--------------|--------------|----------|
| `REM`    | ✅ 安全       | ✅ 安全       | 较低     |
| `::`     | ❌ 可能出错   | ✅ 安全       | 较高     |
| `%注释%` | ✅ 安全       | ❌ 会扩展变量 | 中等     |

### 最佳实践建议：
1. 常规情况优先使用 `::`（更高效）
2. 在代码块内使用 `REM`
3. 避免在行内使用中文注释（可能编码问题）
4. 重要注释使用明显的分隔线：
```batch
REM #####################################
REM # 配置文件生成脚本                 #
REM # 创建时间：2023-01-01             #
REM #####################################
```

### 错误用法示例：
```batch
echo %PATH% :: 这不是注释！会输出"::"
if 1==1 (
  :: 在括号内使用可能报错
  echo test
)
```

> 💡 提示：在`@echo off`模式下，注释内容不会显示在控制台，但会降低脚本执行速度（每行注释需解析）
