### 🧩 基本概念

- `printf` 是 C 语言中最常用的输出函数，用于将格式化的字符串显示到标准输出（通常是屏幕）。
- 定义在 `<stdio.h>` 头文件中。

---

### 📌 函数原型

```c
int printf(const char *format, ...);
```

- `format` 是一个格式字符串，用来指定输出的形式。
- `...` 是可变参数列表，对应格式字符串中的格式控制符。
- 返回值是成功输出的字符数，失败时返回负值。

---

### 🧮 常用格式控制符

| 格式符 | 说明                     | 示例       |
|--------|--------------------------|------------|
| `%d`   | 输出十进制整数            | `printf("%d", 10);` → `10` |
| `%f`   | 输出浮点数                | `printf("%.2f", 3.1415);` → `3.14` |
| `%s`   | 输出字符串                | `printf("%s", "Hello");` → `Hello` |
| `%c`   | 输出字符                  | `printf("%c", 'A');` → `A` |
| `%x`   | 输出十六进制整数          | `printf("%x", 255);` → `ff` |
| `%%`   | 输出一个百分号字符        | `printf("%%");` → `%`     |

---

### 🎨 格式细节示例

你可以使用更多格式化参数来控制输出格式：

```c
printf("%5d", 42);     // 输出： '   42'（总宽度为5，右对齐）
printf("%-5d", 42);    // 输出： '42   '（总宽度为5，左对齐）
printf("%05d", 42);    // 输出： '00042'（不足位用0填充）
```

---

### ⚠️ 注意事项

- 类型与格式符必须匹配，否则输出结果可能不可预测。
- 使用浮点数时，建议指定精度（如 `%.2f`）。
- `printf` 不会自动换行，需手动加上 `\n`。
